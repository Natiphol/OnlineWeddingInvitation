ในชุดนี้มีอะไร
- โค้ดเว็บ HTML / CSS / JavaScript ที่แก้ไขต่อได้ ไม่มีขั้นตอน build
- เสียงญี่ปุ่นและอังกฤษ ภาษาละ 133 ประโยค
- แผนที่ รูปภาพ ฟอนต์ และระบบเตรียมข้อมูลออฟไลน์
- แผนทริปเริ่มต้นตามเวอร์ชันที่เผยแพร่

ทดลองบนคอมพิวเตอร์
1. แตก ZIP ทั้งหมดไว้ในโฟลเดอร์เดียวกัน
2. ถ้าติดตั้ง Python 3 แล้ว เปิด Terminal ในโฟลเดอร์ที่มี index.html
3. รัน: python -m http.server 8000 --bind 127.0.0.1
   บน Windows หากใช้คำสั่ง python ไม่ได้ ให้ลอง py แทน
4. เปิด http://localhost:8000 ในเบราว์เซอร์
5. ปิดเซิร์ฟเวอร์ด้วย Ctrl+C
อย่าเปิด index.html ด้วยการดับเบิลคลิก: JavaScript modules และระบบออฟไลน์ต้องใช้เว็บเซิร์ฟเวอร์

ย้ายไปโฮสต์อื่น
- เป็น static website: อัปโหลดไฟล์ทั้งหมด โดยให้ index.html อยู่ที่รากของเว็บไซต์
- เปิดบริการผ่าน HTTPS เพื่อให้ Service Worker และระบบออฟไลน์ทำงาน
- ไม่ต้องติดตั้ง npm ไม่ต้องใช้ API key ของ OpenAI และไม่ต้องมี ChatGPT Plus เพื่อรันโค้ดชุดนี้บนโฮสต์อื่น
- สิทธิ์เข้าเว็บแบบส่วนตัวของลิงก์เดิมเป็นบริการของโฮสต์เดิม ไม่ได้ติดมาด้วย
  หากต้องการเว็บส่วนตัวบนโฮสต์ใหม่ ต้องตั้งค่าการเข้าถึงของโฮสต์นั้นก่อน
- ตรวจข้อมูลทริปเริ่มต้นใน app.js ก่อนเผยแพร่ให้ผู้อื่น เพราะมีรายละเอียดแผนและที่พักของทริปคุณ

ข้อมูลที่คุณกรอกจริง
ไฟล์ ZIP ไม่รวมรายจ่าย แผนที่แก้ไขเอง ประโยคปักหมุด หรือเอกสารที่อัปโหลดจากมือถือ
ข้อมูลเหล่านี้อยู่ในเบราว์เซอร์ของเครื่องที่คุณใช้งาน
ก่อนย้าย: เปิดเว็บเดิมบนเครื่องนั้น > ทริป > สำรองข้อมูล แล้วบันทึกไฟล์ JSON
หลังย้าย: เปิดเว็บใหม่ > ทริป > นำเข้าข้อมูล แล้วตรวจยอดและเอกสารให้ครบ
ควรเก็บไฟล์สำรองต้นฉบับไว้ด้วย ข้อมูลไม่ย้ายตามอัตโนมัติเมื่อเปลี่ยนลิงก์หรือเบราว์เซอร์
สำหรับอ่านรายจ่ายแยกจากแอป สามารถส่งออก HTML หรือ CSV จากหน้ารวมทั้งทริป

ใช้บนมือถือแบบออฟไลน์
1. เปิดเว็บ HTTPS ใน Safari / Chrome ขณะมีอินเทอร์เน็ต
2. เพิ่มไว้บนหน้าจอโฮม เปิดจากไอคอนนั้นขณะออนไลน์
3. เข้า ทริป > เตรียมออฟไลน์ รอทุกหมวดครบ
4. เปิดโหมดเครื่องบิน ปิดแล้วเปิดจากไอคอนเดิม ทดสอบบันทึกเงินและเล่นเสียง
การแปลผ่าน Google Translate และอัปเดตอัตราแลกเปลี่ยนยังต้องใช้อินเทอร์เน็ต
ข้อมูลออฟไลน์อาจสูญหายเมื่อผู้ใช้ล้างข้อมูลเว็บไซต์ หรือระบบลบพื้นที่จัดเก็บ จึงควรมีไฟล์สำรอง

ชุดนี้เป็นสำเนาของเว็บ ไม่ได้เปลี่ยนแปลงลิงก์เดิม
