ชุดอัปเดตสำหรับ https://natiphol.github.io/TravelJapan/

ติดตั้ง (ไม่ต้องอัปโหลดเสียงใหม่)
1. สำรองข้อมูลจากเว็บเดิมบนเครื่องที่ใช้จริง เก็บ JSON ไว้ในคอม/มือถือ ไม่ต้องอัปโหลด JSON ส่วนตัวเข้า GitHub
2. แตก ZIP นี้
3. เปิดหน้าหลัก Repository TravelJapan > Add file > Upload files
4. อัปโหลด 6 ไฟล์พร้อมกัน: index.html, app.js, style.css, travel-data.js, sw.js, version.json
   ให้อยู่ข้างโฟลเดอร์ audio / maps / fonts เดิม ไม่สร้างโฟลเดอร์ v1.0.7 ครอบ
5. Commit changes รอ GitHub Pages เผยแพร่สำเร็จ
6. ปิดแท็บเว็บเดิมทั้งหมด แล้วเปิดใหม่ขณะมีเน็ต หากยังแสดงรุ่นเก่าให้รีโหลดและปิดเปิดอีกครั้ง
   เวอร์ชันเก่ายังไม่มีปุ่มอัปเดต ต้องเข้ารุ่นนี้ก่อนจึงจะใช้ปุ่มในรอบถัดไปได้
7. ตรวจท้ายหน้าเห็น v1.0.7 แล้วไป ทริป > เตรียมออฟไลน์ ให้ครบอีกครั้ง
8. ทดสอบบนมือถือจริงด้วยโหมดเครื่องบิน: เปิดแอป บันทึกเงิน เล่นเสียง เปิดแผนที่ และ SOS
ไม่ต้องล้างข้อมูลเว็บไซต์ การอัปเดตยังใช้ข้อมูลในเครื่องเดิม

สิ่งที่เพิ่ม
- เริ่มต้นทริปว่าง ไม่มีวัน Disneyland หรือคำตอบ ตม. ที่ระบุทริป/อาชีพของเจ้าของเว็บ
- สมาชิก 1–20 คน เลือก 1/2/3/4 หรือเพิ่มเอง คนแรกคือเจ้าของบัญชีในเครื่องนั้น
- เลือกเฉพาะผู้ร่วมค่าใช้จ่าย ระบุผู้จ่าย หารเท่ากันหรือกรอกส่วนแบ่งเอง
- เศษสตางค์จัดตามลำดับชื่อ ยอดรวมส่วนแบ่งตรงกับยอดจ่าย
- ยอดค้างคืนรายคน แยกบาท/เยน รับคืนจากร้าน คืนเงินระหว่างคน และรายงานส่วนแบ่ง
- รับไฟล์สำรองเดิมสองคนได้ ไฟล์หลายคนรุ่นใหม่ควรนำเข้าที่ v1.0.7 ขึ้นไป
- ไม่ให้ลดจำนวนสมาชิกเมื่อมีประวัติการเงินเพื่อป้องกันหนี้และรายการเดิมผิดคน เปลี่ยนชื่อได้ เพิ่มคนได้
- ตอนนี้: Tokyo/Osaka weather, เรท JPY/THB, ข้อมูลแผ่นดินไหวที่รายงานแล้ว, ช่องเก็บเที่ยวบินและผลตรวจสถานะ
- SOS: โทร 110 / 119, ที่พักคืนนี้, ผู้ติดต่อ, ประกัน, กงสุล, ประโยคแสดงตัวใหญ่
- Places: เพิ่ม/แก้ไข/ลบ ปักดาว เช็กว่าไปแล้ว ส่งสถานที่เข้าแผนโดยให้เลือกวันก่อนบันทึก
- คู่มือ JR/Yamanote, Kyoto, Disney, Fuji, Shinkansen, IC Card พร้อมแหล่งทางการ
- วันนี้: กลับที่พักคืนนี้ เข้าหน้าตอนนี้ จดเงิน ประโยคปักหมุด
- เวอร์ชันและปุ่มตรวจ/ติดตั้งอัปเดตในหน้าทริป

LIVE ที่มีจริงและขอบเขต
- อากาศ: ดึง Open-Meteo เมื่อเข้าหน้าตอนนี้ขณะออนไลน์ (จำกัดความถี่อย่างน้อย 15 นาทีระหว่างการเข้าหน้า) หรือกดอัปเดตเอง เก็บผลสำเร็จและเวลาไว้ในเครื่อง
- อากาศมาจากแบบจำลอง ไม่ใช่เซนเซอร์ ณ ตำแหน่งผู้ใช้ แสดง Tokyo/Osaka ตามพิกัดเมือง
- Open-Meteo free endpoint สำหรับใช้งานไม่เชิงพาณิชย์ มีข้อจำกัดการใช้งาน หากเปลี่ยนเป็นบริการเชิงพาณิชย์ต้องตรวจสิทธิ์/แผนของผู้ให้บริการ
- แผ่นดินไหว: USGS เหตุ M4+ ที่รายงานใน 24 ชั่วโมง บริเวณ 24–46N / 122–150E สูงสุด 20 เหตุ
  เป็นข้อมูลเหตุที่เกิดแล้ว ไม่ใช่คำเตือนก่อนเกิดเหตุ/สึนามิ ไม่ครอบคลุมทุกเหตุ ไม่มีแจ้งเตือน push เมื่อปิดแอป
- เที่ยวบิน/Delay รถไฟหยุด พายุ: ยังไม่ได้เชื่อม API อัตโนมัติ มีลิงก์ทางการและฟอร์มบันทึกผลตรวจพร้อมเวลา
  ไม่แสดงว่าปกติหากไม่มีข้อมูล ไม่อ้างว่าลิงก์ภายนอกหรือผลตรวจเก่าเป็น LIVE
- เรท Frankfurter เป็นเรทอ้างอิงรายวัน ไม่ใช่ราคาหน้าร้านหรือราคา tick แบบ real-time
- หากอัปเดตล้มเหลวเก็บข้อมูลสำเร็จครั้งก่อนและเวลาเดิม หากไม่เคยดึงสำเร็จแสดงว่ายังไม่มีข้อมูล
- SOS และข้อมูลที่บันทึกอ่านออฟไลน์ได้ แต่การโทรต้องมีเครือข่ายโทรศัพท์ และเว็บภายนอกต้องใช้อินเทอร์เน็ต

เวอร์ชันรอบถัดไป (สำหรับผู้ดูแล)
เปลี่ยน APP_VERSION ใน app.js และ version ใน version.json ให้ตรงกัน
เปลี่ยนชื่อ CACHE ใน sw.js และเลข query ของ app/style/travel-data ให้ตรงกันทั้ง index.html, app.js, sw.js
Worker ใหม่รอผู้ใช้กดติดตั้ง จึงไม่บังคับรีโหลดระหว่างกรอกฟอร์ม ไม่ลบ localStorage หรือ IndexedDB
เก็บไฟล์เวอร์ชันเก่าไว้เพื่อรองรับแท็บที่ยังเปิดอยู่ได้ตามต้องการ แคชเก่าไม่ถูกล้างอัตโนมัติในรุ่นนี้

การตรวจที่ทำแล้ว
- ทดสอบจำลอง DOM: สร้างทริป 4 คน / หาร 3 คน / แก้รายการ / บาทและเยน / เงินคืน / สรุปยอด / ส่งออก / นำเข้ารุ่นเก่าและคนเดียว
- ทดสอบ Places, SOS, บันทึกผลตรวจเที่ยวบิน และโหลดข้อมูลที่บันทึกหลังเปิดใหม่
- ทดสอบ API ตอบจริงและอนุญาต cross-origin สำหรับ Open-Meteo / USGS
- ทดสอบจำลองออฟไลน์และ retry ไฟล์ขาด Worker รอคำสั่งติดตั้ง
- ยังไม่ได้ทดสอบ UI และเสียงบนมือถือจริงของผู้ใช้
