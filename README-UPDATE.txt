ICHI-JAPAN: ชุดอัปเดตเริ่มต้นว่างสำหรับผู้ใช้ทั่วไป
อัปโหลด 3 ไฟล์ app.js, index.html, sw.js ทับไฟล์ชื่อเดิมที่หน้าหลักของ Repository แล้ว Commit changes
ไม่ต้องอัปโหลดเสียง แผนที่ หรือฟอนต์ใหม่ หากมีครบอยู่แล้ว
ผู้ใช้ใหม่พบหน้าต้อนรับ ตั้งทริปเอง ไม่มีแผนและโรงแรมของเจ้าของเว็บ
ข้อมูลของผู้ใช้เดิมไม่ถูกลบ หากยังเห็นทริปเดิมเป็นข้อมูลในเครื่อง ให้ใช้หน้าต่างไม่ระบุตัวตนทดสอบผู้ใช้ใหม่
หากคุณต้องการเริ่มทริปว่างในเครื่องเดิม ให้สำรองข้อมูลก่อน แล้วไป ทริปของฉัน > สร้างทริป
ข้อมูลแต่ละคนเก็บในเครื่อง ไม่มีระบบล็อกอินหรือซิงก์ข้ามเครื่อง
รอ GitHub Pages เผยแพร่เสร็จ จากนั้นปิดแท็บเว็บเดิมทั้งหมดแล้วเปิดใหม่ขณะออนไลน์ หากยังเก่าให้รีโหลดอีกครั้ง
การอัปเดตไฟล์ไม่ได้ลบประวัติ Git: รายละเอียดทริปเดิมอาจยังอยู่ใน commits เก่าของ Repository
