ICHI-JAPAN v1.5.6 — Transportation
Released: 1 Oct 2026

ฐานเวอร์ชัน: v1.5.5 Data Quality
รอบนี้ทำระบบ Transportation แบบ A → B ให้จริงจังขึ้น โดยไม่รื้อ Dashboard หรือฐานข้อมูล Discover เดิม

สิ่งที่เพิ่ม
1) Structured Route ต่อทุกช่วงในแผน
แต่ละช่วง สถานที่ A → สถานที่ B สามารถบันทึก:
- รูปแบบการเดินทาง: รถไฟ/Metro, Bus, เดิน, Taxi, อื่น ๆ
- สถานี/ป้ายต้นทาง
- สถานี/ป้ายปลายทาง
- สายรถไฟ / ขบวน / สายรถบัส
- จุดเปลี่ยนสาย
- ชานชาลา / ทิศทาง
- Exit เมื่อถึง
- เวลาโดยประมาณ (นาที)
- ค่าโดยสารโดยประมาณ (เยน)
- หมายเหตุสำหรับอ่านออฟไลน์
- วันที่บันทึกล่าสุด

2) Offline Route Pack
Dashboard / หน้าแผน / หน้าเดินทางสามารถเปิด Route Pack ของวันนั้นได้
Route Pack แยกสถานะ:
- Route Ready: รายละเอียดหลักครบ
- Route Saved: บันทึกแล้วแต่ยังควรเติมสถานี/สาย/เวลา
- Missing: ยังไม่มีเส้นทาง

3) Dashboard ตรวจ Route ละเอียดขึ้น
เดิมดูแค่ว่ามีข้อความ Route หรือไม่
v1.5.6 แยก:
- บันทึก Route แล้วกี่ช่วง
- รายละเอียดพร้อมใช้งานจริงกี่ช่วง
- ขาด Route กี่ช่วง
- Route ที่บันทึกแล้วแต่ควรเติมรายละเอียดกี่ช่วง

4) Smart Logic ใช้เวลาเดินทางแบบ Structured ก่อน
Time Conflict / Live Trip จะใช้ durationMinutes ที่บันทึกใน Route ก่อน
ถ้าไม่มี จึงค่อยอ่านเวลาจากหมายเหตุเก่า
ถ้ายังไม่มีทั้งสองอย่าง ระบบอาจใช้ค่าประมาณระดับย่านเพื่อเตือนเท่านั้น

5) หน้าแผนเที่ยวอ่าน Route ง่ายขึ้น
ใต้แต่ละจุดจะแสดงการ์ด Route สั้น ๆ เช่น:
Shinjuku Station → Shibuya Station
JR Yamanote Line · 18 นาที · ¥180 · Exit Hachiko
พร้อมปุ่ม Google Maps และแก้ Route

6) Live Trip
ถ้าช่วงปัจจุบันมี Route ที่บันทึกไว้ จะขึ้น Offline Route Card:
- ต้นทาง / ปลายทาง
- สาย
- เวลา
- ค่าโดยสาร
- Exit
- จุดเปลี่ยน / ทิศทาง
พร้อมใช้ข้อมูลเวลา Route เพื่อช่วยคำนวณว่า “ควรออกเมื่อไร”

7) หน้า เดินทาง > ขึ้นรถที่ไหน
เพิ่ม MY TRANSPORTATION ของวันในแผนไว้ด้านบน
เห็น Route Saved % และเปิด Route Pack ได้ทันที
ส่วน Route Guide สนามบิน/เมืองเดิมยังอยู่ครบ

ความเข้ากันได้กับข้อมูลเดิม
- localStorage ยังใช้ key `tabi-v1`
- Route แบบเก่าที่มีแค่ข้อความยังอ่านได้ และนับเป็น “บันทึกแล้ว”
- ระบบจะแนะนำให้เติม Station / Line / Duration เพื่อให้ Live Trip และ Time Conflict ทำงานแม่นขึ้น
- Backup JSON เดิมยังนำเข้าได้

ข้อควรเข้าใจ
- Google Maps ต้องใช้อินเทอร์เน็ต
- Route Pack และหมายเหตุที่บันทึกเปิดอ่านจากข้อมูลในเครื่องได้
- เวลา ค่าโดยสาร ชานชาลา Exit และเส้นทางจริงสามารถเปลี่ยนได้ ควรตรวจป้าย/Google Maps/ผู้ให้บริการในวันเดินทาง
- v1.5.6 ไม่ดึงตารางรถไฟสดหรือค่าโดยสารสดอัตโนมัติ
